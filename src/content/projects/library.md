## Overview

Library is an e-commerce app for buying books, built as a personal project while learning React. The main goal was to get comfortable with component architecture, state management, and building something that feels like a real product.

## Features

- Product catalogue with filtering
- Skeleton loading states (so the UI doesn't flash blank while data loads)
- Cart with item management
- Responsive layout

## Notes

This was built before my apprenticeship and is included here as context for where I started. The code reflects what I knew at the time — it's not how I'd approach it now, but it was the project that made React click for me.
